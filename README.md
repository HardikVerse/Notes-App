# Notes App 

A simple Notes Application built while learning full-stack web development.

##  Features

- User Signup
- User Signin
- JWT-based Authentication
- Protected Notes API
- Create and View Personal Notes
- User-specific Notes

## Technologies Used

- HTML
- JavaScript
- Axios
- Node.js
- Express.js
- JSON Web Token (JWT)

## Project Structure

```text
Notes-App/
│
├── Frontend/
│   ├── index.html
│   ├── signin.html
│   └── signup.html
│
├── authmiddleware.js
├── index.js
├── package.json
├── package-lock.json
└── .gitignore
```

##  How to Run

1. Clone or download this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the backend server:

   ```bash
   node index.js
   ```

4. Open the application in your browser through the server.
